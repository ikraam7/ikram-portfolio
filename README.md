# Portfolio — Ikram LAABOUKI

Portfolio personnel statique (FR/EN), prêt pour GitHub Pages.

## Déploiement
1. Créer un dépôt public GitHub, par exemple `ikram-portfolio`.
2. Ajouter **le contenu de ce dossier** à la racine de la branche `main` (pas le ZIP lui-même).
3. Dans le dépôt : **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
4. Après publication, l’URL sera généralement `https://VOTRE-PSEUDO.github.io/ikram-portfolio/`.

## Arborescence
- `index.html` : site et boutons CV adaptatifs selon langue
- `CV_Ikram_LAABOUKI_FR.pdf`, `CV_Ikram_LAABOUKI_EN.pdf` : CV français et anglais
- `captures/` : captures des projets
- `videos/` : vidéos de démonstration
- `reports/` : rapports PDF
- `certificates/` : attestations MLIAEdu

**Avant publication :** vérifier les PDF et vidéos pour éviter toute divulgation de secrets, identifiants ou données personnelles. Les fichiers d’un dépôt public et les médias du site sont accessibles à tous.
